# Quick Notes App ✨

A simple and beautiful notes application built with HTML, CSS, and JavaScript. Create, customize, and manage your notes easily with an intuitive interface.

## Features

- **Create Notes** - Add new notes instantly with one click
- **Pin Notes** - Pin important notes to keep them at the top
- **Lock/Edit** - Lock notes to prevent accidental changes
- **Color Themes** - Choose from 5 different color themes for each note
- **Delete Notes** - Remove notes you no longer need
- **Beautiful UI** - Clean gradient background with modern design

## Installation

1. Clone the repository
```bash
git clone https://github.com/Harshdev04/Notes-App.git
```

2. Navigate to the project folder
```bash
cd Notes-App
```

3. Open `index.html` in your browser

That's it! No dependencies or build process required.

## Usage

1. Click the **"+ New Note"** button to create a new note
2. Type your content in the text area
3. Click the **📌 pin button** to pin/unpin the note
4. Click **color circles** to change the note's background color
5. Click **🔒 Lock** to lock the note (prevents editing)
6. Click **✏️ Edit** to unlock and edit again
7. Click **🗑️ Delete** to remove the note
